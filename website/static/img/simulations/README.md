# Simulation Visual Assets

This directory contains simulation images and diagrams used throughout the textbook.

## Required Images

- `robot-gazebo.png` - Example of a robot in Gazebo simulation
- `isaac-sim.png` - NVIDIA Isaac Sim environment screenshot
- `unity-ros.png` - Unity simulation with ROS integration
- `vla-model-diagram.png` - Vision-Language-Action model architecture

## Image Guidelines

- **Format**: PNG or JPEG
- **Resolution**: 1920x1080 or higher for screenshots
- **File Size**: Optimize to < 500KB per image
- **Naming**: Use kebab-case (lowercase with hyphens)
